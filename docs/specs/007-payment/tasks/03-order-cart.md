- [x] **T7303** [テスト] 注文の単体テスト（BR-14）：

  - 支払待ち → 受付。受付・キャンセルで与信の成功を受けても変わらない
  - 支払待ち → キャンセル（支払期限切れ）。運営者と理由を持たない（AC-155）
  - 支払待ちは、申請も運営者のキャンセルもできない（AC-158）

  - 注文すると、在庫数が減り、支払（未払い）が作られ、カートは変わらない（AC-144）
  - 与信の成功で受付になり、注文した品目だけがカートから除かれる（AC-146、147）
  - 支払の期限切れでキャンセルになり、在庫が戻り、調整履歴の理由は「注文のキャンセル」（AC-153、155）

  - 受付・キャンセル申請中の注文のキャンセル（承認、運営者の判断）で、支払が与信の取消待ちになる。キャンセルは取消の結果を待たない（AC-162、163）

  - 管理画面：状態「支払待ち」の絞り込み、一覧と詳細の支払の状態（AC-160、161）
