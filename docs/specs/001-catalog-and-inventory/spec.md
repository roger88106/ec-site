# Spec 001：商品カタログと在庫

ステータス：確定

## 1. 背景と目的

コアフローの出発点として、**運営者が商品を登録・公開し、消費者がそれを閲覧できる状態**を作る。

- 運営者が、商品の価格と、バリアント（色・サイズ違いなど）ごとの在庫を管理できる。価格は商品単位で、バリアント間で共通とする。
- 消費税は税区分と期間付きの税率で管理し、税率が変わってもコード変更なしで対応できる。
- 消費者が、公開中の商品を一覧・検索し、税込価格と在庫の有無を確認できる。

在庫は「運営者が数量を管理し、消費者が在庫の有無を見られる」までとする。注文による引当・減算はカート・注文の spec で扱う。

## 4. User stories と受け入れ条件

### US-1 税区分と税率を管理する（B / P1）

税率の改定や期間限定の税率変更に、システムの改修なしで対応したい。

権限：`tax:read`、`tax:write`

- **AC-1** 税区分を名称で登録できる。名称は重複できない。
- **AC-2** 税率は、率（%）、適用開始日時、適用終了日時を持つ。開始が空白なら「過去全て」、終了が空白なら「無期限」を意味する。終了日時ちょうどは含まない。
- **AC-3** 税区分の税率は、一覧としてまとめて登録・更新する。次を全て満たさない一覧は、全体が拒否される。
  - 期間が重複しない（空白は無限として扱う）
  - 期間の間に途切れがない
  - 最後の税率の終了日時は空白
- **AC-4** 期間限定の税率に切り替え、元に戻せる（日時は全て日本時間。BR-3）。
  - Given：「標準」に 10%（開始・終了とも空白）がある。現在は 2026-10-08
  - When：一覧を「10%（〜2027-04-01 00:00）」「8%（2027-04-01 00:00〜2028-04-01 00:00）」「10%（2028-04-01 00:00〜）」に更新する
  - Then：2027-03-31 23:59 は 10%、2027-04-01 00:00 から 2028-03-31 23:59 は 8%、2028-04-01 00:00 以降は 10% で計算される
- **AC-5** 過去の根拠を変えない。
  - 現在より前の日時を、開始・終了として新たに設定できない（空白は可）。
  - 開始済みの税率（開始が空白のものを含む）は、率と開始日時を変更できず、削除もできない。終了日時は、現在より後の日時に変更できる。
  - 終了済みの税率は変更できない。未開始の税率は変更・削除できる。
- **AC-6** 現時点で有効な税率を持たない税区分は、商品に割り当てられない。
- **AC-7** 税率は 0% 以上 100% 未満。

### US-2 カテゴリを管理する（B / P1）

権限：`category:read`、`category:write`

- **AC-8** カテゴリを、名称と親カテゴリ（任意）で登録できる。親がなければ最上位になる。
- **AC-9** 階層は最大 3 階層。4 階層目の登録は拒否される。
- **AC-10** 同じ親の下で名称は重複できない。
- **AC-11** 名称と、兄弟カテゴリ間の並び順を変更できる。
- **AC-12** 子カテゴリを持つ、または商品が所属しているカテゴリは削除できない。

### US-3 商品を登録・編集する（B / P1）

権限：`product:read`、`product:write`

- **AC-13** 商品品番、商品名、説明、税区分、税抜価格、所属カテゴリ（0 個以上、複数可）、バリアント軸（0〜3 個）を指定して登録できる。
- **AC-14** 商品品番は全商品で一意。
- **AC-15** 商品品番は半角の英大文字・数字とハイフンで 1〜32 文字。ハイフンは英数字の間にだけ置ける（先頭・末尾・連続は不可。例：`ABC-001` は可、`-ABC`、`ABC--1`、`abc-001` は不可）。登録後は画面・API から変更できない。
- **AC-16** 税区分は必須。
- **AC-17** 登録直後の商品は非公開。
- **AC-18** 商品名、説明、税区分、税抜価格、所属カテゴリは変更できる。
- **AC-19** 税区分を変更すると、税込価格が変更後の税率で計算される。
- **AC-25** 税抜価格は 1 円以上の整数。
- **AC-26** 価格の変更は C 側に反映される（NFR-1）。

### US-4 バリアントを登録・編集する（B / P1）

権限：`product:read`、`product:write`

バリアントは価格を持たない。価格は商品の価格を使う（US-3）。

- **AC-20** バリアント品番と軸の値（例：色＝白、サイズ＝M）を指定してバリアントを登録できる。
- **AC-21** バリアント品番は全バリアントで一意。形式と変更不可の扱いは AC-15 と同じ。
- **AC-22** 商品に軸があれば、バリアントは全ての軸の値を持つ。
- **AC-23** 同じ商品の中で、軸の値の組み合わせは重複できない。
- **AC-24** 軸を持たない商品のバリアントは 1 つだけ。
- **AC-27** バリアントの表示順を変更できる。
- **AC-28** バリアントを販売停止・解除できる。販売停止中のバリアントも C 側の選択肢には表示するが、選択できない（在庫切れと同様に、選べない状態として示す）。（P2）
- **AC-71** C 側に一度も表示されていない商品のバリアントは削除できる。表示されたことのある商品のバリアントは削除できない。

### US-5 商品を公開・非公開にする（B / P1）

権限：`product:write`

- **AC-29** 公開にすると、C 側の一覧・検索・詳細に表示される。
- **AC-30** 非公開にすると、C 側に表示されない。
- **AC-31** バリアントのない商品は公開できない。
- **AC-32** 状態は「非公開」「公開」「販売終了」。販売終了の商品は C 側に表示されず、公開に戻せない。
- **AC-33** C 側に一度も表示されていない商品は削除できる。表示されたことのある商品は削除できず、販売終了にする。公開の予約（US-6）をしただけで、開始日時の前に取り消した商品は、表示されていないものとして扱う。

### US-6 公開日時を予約する（B / P2）

権限：`product:write`

- **AC-34** 公開開始日時と公開終了日時（いずれも任意）を設定できる。
- **AC-35** 公開状態でも、開始日時より前と終了日時以降は C 側に表示されない。運営者の操作なしに、その時刻で切り替わる。
- **AC-36** 終了日時は開始日時より後。

### US-7 商品画像を登録する（B / P2）

権限：`product:write`

- **AC-37** 商品に画像を複数登録し、並び順を変えられる。先頭が代表画像。
- **AC-38** バリアントに画像を 1 枚指定できる（任意）。なければ商品の代表画像を使う。
- **AC-39** 形式は JPEG、PNG、WebP（US-13 で、AC-67 の形式を追加する）。1 ファイル 10MB まで。
- **AC-40** 1 商品あたり最大 20 枚。

US-13 までは、画像をそのまま配信する（位置情報などのメタデータが残る）。

### US-8 在庫を調整する（B / P1）

権限：`inventory:read`、`inventory:write`

- **AC-41** 新しいバリアントの在庫数は 0。
- **AC-42** 在庫数は、増減量（例：+10、-3）と理由で調整する。直接上書きする操作はない。
- **AC-43** 調整後に負になる調整は拒否される。
- **AC-44** 同じバリアントへの調整が同時に実行されても、全て反映される。
  - Given：在庫数 10
  - When：+5 と +3 が同時に実行される
  - Then：在庫数は 18
- **AC-45** 調整履歴（日時、増減量、理由、調整後の在庫数）を新しい順に参照できる。
- **AC-46** 理由は「入荷」「棚卸差異」「破損・紛失」「その他」。「その他」はメモ必須。

### US-9 商品を一覧・絞り込みする（運営者）（B / P1）

権限：`product:read`

- **AC-47** 状態に関係なく、全ての商品を一覧できる。
- **AC-48** 商品品番・バリアント品番の前方一致、商品名の部分一致、状態、カテゴリで絞り込める。
- **AC-49** 商品品番、商品名、状態、バリアント数、在庫数の合計を表示する。
- **AC-50** ページ単位で取得できる。

### US-10 商品を一覧・絞り込みする（消費者）（C / P1）

- **AC-51** C 側に表示される商品（BR-2）だけが含まれる。
- **AC-52** カテゴリで絞り込める。子孫カテゴリの商品も含む。
- **AC-53** 税込価格の範囲で絞り込める。
- **AC-54** 新着順（既定）、価格の安い順、高い順で並べ替えられる。新着順の基準は、最初に C 側へ表示された日時（予約公開なら公開開始日時）。再公開しても順位は上がらない。
- **AC-55** 商品名、代表画像、価格（BR-4）を表示する。
- **AC-56** 全バリアントが在庫切れの商品も表示し、「在庫なし」と示す。
- **AC-57** ページ単位で取得できる。

### US-11 商品をキーワードで検索する（C / P1）

- **AC-58** 商品名または説明にキーワードを含む商品が表示される。
- **AC-59** 対象は C 側に表示される商品（BR-2）だけ。
- **AC-60** 精度（表記ゆれ、類義語、関連度順）は問わない。
- **AC-61** ページ単位で取得できる。

### US-12 商品の詳細を見る（C / P1）

- **AC-62** 商品名、説明、画像、価格（BR-4）、バリアント軸と選択肢を表示する。選択肢には、在庫切れや販売停止で選べない値も含め、選べない状態として示す。
- **AC-63** バリアントを選ぶと、その在庫状況を表示する。
- **AC-64** 在庫状況は「在庫あり」「在庫なし」のみ。数量は表示しない。
- **AC-65** C 側に表示されない商品は、存在しない商品と同じ結果になる。
- **AC-66** URL は品番が変わっても変わらない。

### US-13 スマートフォンの画像形式を受け付け、WebP に変換する（B / P2）

権限：`product:write`

- **AC-67** BMP、HEIC / HEIF など一般的な画像形式も受け付ける（対応形式は plan で確定）。
- **AC-68** 全ての画像を WebP に変換して配信する。
- **AC-69** 変換時に位置情報などのメタデータを除去する。
- **AC-70** 変換に失敗した画像は登録されず、運営者にその旨が表示される。

## 5. 業務ルール

- **BR-1 税込価格**：税抜価格 ×（1 ＋ 表示時点の税率）。1 円未満は切り捨て。
  - 例：1,800 円・10% → 1,980 円。1,234 円・8% → 1,332 円
- **BR-2 C 側に表示される商品**：状態が「公開」で、公開期間内（US-6）であること。
- **BR-3 日時**：画面での入力・表示は日本時間。
- **BR-4 価格の表示**：税込価格を主に、税抜価格を括弧で併記する（例：「1,980 円（税抜 1,800 円）」）。
- **BR-5 品番**：品番は識別子ではなく属性。DB を直接更新して付け替えても、他のデータとの関係が壊れないこと（constitution 7.1）。

## 6. 非機能要件

- **NFR-1** 商品、価格、公開状態、在庫の変更は、1 分以内に C 側へ反映される。
