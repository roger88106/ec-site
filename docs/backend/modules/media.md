# メディアモジュール

利用者がアップロードするファイル（今は画像だけ）の受け付け、検証、保存、配信 URL、削除を担う。
ファイルが何に使われるか（どの商品の何枚目か、代表画像か）は知らず、使う側（商品カタログなど）が持つ。

| 項目 | 内容 |
|------|------|
| レベル | B（業務の不変条件はなく、ストレージとの連携が中心） |
| 依存 | なし（使う側から API で呼ばれる） |
| 関連 spec | [001](../../specs/001-catalog-and-inventory) |
| 範囲外 | サイトの静的ファイル（ロゴ、CSS、JavaScript）。フロントのビルド成果物として、フロントの配信（CDN）が出す |

## アセット

アセットは、検証して配信の場所に置いた 1 つのファイル。ID、形式（JPEG など）、配信キーを持つ。

- 使う側はアセット ID だけを持つ。配信キーや URL の形は外に出さない。
- 配信キーはアセット ID で作り（`assets/{assetId}.{拡張子}`）、上書きしないので長くキャッシュさせる。
- アセットは使う側が持ち主として扱い、要らなくなったら手放す。複数の持ち主で共有しない。

## アップロードの流れ

ファイルはブラウザから受付バケットへ直接送る（署名付き URL）。バックエンドは中継しない。

1. **受付**（`requestImageUpload`）：形式と大きさを確かめ、受付バケットへの署名付き URL を返す。DB には記録しない。
   - 使う側は持ち主を表す範囲（商品 ID など）を渡す。受付のキーは `{範囲}/{uploadId}` で、別の範囲の受付を確定できない。
   - 枚数の上限など使う側の規則は、使う側が受付の前に確かめる。
2. **確定**（`confirmImage`）：受付のファイルの大きさと、先頭のバイトで判定した形式を確かめ（申告は信用しない）、WebP に変換して配信バケットへ置き、アセットを記録してアセット ID を返す。
   - 使う側のトランザクションの中で呼ぶ。使う側の保存が失敗すると、アセットの記録も取り消される（配信のファイルは残るが、だれも参照しない）。
   - 変換は imgproxy で同期に行い、向きを画素に反映してメタデータを除く ※1。
3. 確定しなかったファイルは、受付バケットのライフサイクル規則で 1 日後に消える。

※1：imgproxy のエラー、時間切れ、応答が WebP でない（先頭のバイトで判定）ときは、その場でエラーにしてアセットを記録しない。

### 受け付ける画像

| 項目 | 決まり |
|------|--------|
| 形式 | JPEG、PNG、WebP、BMP、HEIC / HEIF、AVIF。確定のときに先頭のバイトで判定する |
| 大きさ | 1 バイト以上、10MB まで |
| 配信の形式 | すべて WebP ※2 |

※2：WebP 変換を入れる前に確定したアセットは、受け付けた形式のまま。

使う側で決まりを変える必要が出たら、受付・確定に決まりを渡せるようにする。

## アセットを手放す

使う側は、アセットが要らなくなったら（画像の削除、商品の削除）、自分のトランザクションの中で `release` を呼ぶ。

- アセットの記録を消し、内部のイベント（アセット解放）を登録する。配信のファイルはコミット後にそのイベントで消す（使う側の保存が失敗すれば、解放も取り消される）。
- ファイルの削除は冪等なので、イベントが重ねて届いてもよい。解放済みのアセットを手放しても成功にする。

## ストレージと変換

| 役割 | port | 実装 | 設定 |
|------|------|------|------|
| ストレージ | `ObjectStorage` | Amazon S3（AWS SDK v2）。ローカルと CI は SeaweedFS | `ecsite.media.storage` |
| 画像の変換 | `ImageConverter` | 別コンテナの imgproxy を HTTP で呼ぶ | `ecsite.media.converter` |

ストレージの操作は、AWS（S3）と GCP（GCS）の両方にあるものだけにする（署名付き PUT の URL、ファイルの情報、先頭の読み取り、書き込み、削除）。

## 他のモジュールへの公開

| 種類 | 内容 | 利用者 |
|------|------|--------|
| API | 画像のアップロードの受付・確定、アセットの解放、配信 URL の取得（まとめて） | 商品カタログ |

イベント（アセット解放）はモジュールの中だけで使う。
