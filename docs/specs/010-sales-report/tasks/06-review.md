## 結果

### 修正したこと

| 対象 | 修正したこと |
|------|------------|
| バックエンド | レポートの腐敗防止層とリポジトリの、インターフェースを実装するメソッドに Javadoc を追加した。インスタンスを作らないクラスを Lombok の `NoArgsConstructor`（PRIVATE）にした |
| 管理画面の構成 | 条件の商品の選択肢が 100 件までであることを書いた |
| CI の検査（T0505） | テスト名の AC の範囲の表記を 1 つずつにし、AC-211、216 をテストに対応させた。表示の文言の検査で検出された箇所を修正した。ローカルで実行する CI の検査に、この 3 つを追加した（skill `local-dev`） |
| 機能紹介のページ | レポートの 3 つの画面を追加し、管理画面の画像をメニューの「レポート」の入ったものに再撮影した。ロードマップのレポートを完成にし、条件・テスト・仕様書の数を修正した |

### 修正せずに残したこと

| 内容 | 理由 |
|------|------|
| 条件の商品の選択肢は、商品の一覧の API の 1 ページ（100 件）まで | 今の商品の数（seed で 15）では足りる。増えたら検索して選択する方式に変更する（管理画面の構成に書いた） |
| 写しの都道府県は、名前からコードへの読み替えの表で変換する | 注文がお届け先をコードで持つようになるまでの間の形（レポートモジュールの設計書） |

### 性能（plan 第 9 節）

- API：[段階 3 の測った結果](03-seed.md) のとおり、2 年分・2 万件の注文で、どのレポートも初回 0.42 秒以内（上限は 1 秒）。索引は追加していない。
- 画面：2 年分の期間で、ページを開いてから表が出るまで、売上の推移（週、105 行）0.89 秒、バリエーションの売れ行き 0.63 秒、地域・年齢層・性別 0.98 秒（上限は 3 秒）。2026-10-15、開発マシンの開発サーバーで、管理職でログインした状態で測った。
