- [x] **T018-02-02** 同じ文書に、サブエージェントに任せる作業とモデルの表を書く（DC-201）。

  - 結果：消費が増えることは事実だった。Haiku 5.5 は、指示が 10 万 token を超えると、すべての単価が 5 倍になる（Anthropic の料金の文書）。品質が落ちることは確かめられなかった。Haiku に任せる作業を、10 万 token を超えないものに限った。
