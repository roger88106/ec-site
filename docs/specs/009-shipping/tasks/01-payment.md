## API

- [x] **T9106** [テスト] 売上確定の統合テスト：
  - 与信済みの支払を確定すると売上確定済みになる
  - 売上確定済みなら決済サービスを呼ばずに成功する
  - 決済サービスが期限切れで拒否したら与信期限切れになり、業務のエラーを返す
  - 接続できなければ与信済みのまま、システムのエラーを返す
- [x] **T9107** 決済の API に売上確定を追加する。T9106 を通す。
- [x] **T9108** [テスト] 返金の統合テスト：
  - 売上確定済みの支払を取り消すと返金待ちになり、コミットの後に返金して返金済みになる
  - 決済サービスが失敗したら返金待ちのまま残り、再発行で返金される
  - 返金済みの支払を重ねて取り消しても、成功し、変わらない
- [x] **T9109** 返金を実装する（plan 第 3.3 節）。T9108 を通す。
- [x] **T9110** 決済の API で、注文 ID ごとの与信期限と「期限が近い」、期限が近い注文 ID の一覧を返す。統合テストを追加する。
