### T6904 の結果：完了の確認

段階 9 の完了条件を満たした。DC と DN は全て満たす（T6903 の表）。全てのテスト、E2E、CI の検査が通る。

レビューで修正したこと：

- 店舗画面の `<form action>` の文字列の URL を、レビューで確認する所に追加した（フロントの書き方 第 6 節）。
- API の列挙の値から組み立てる文言のキーを、キーの形の例外にした（同 第 7.2 節）。
- 画面の構成の文書に、文言の道具と置き場所、店舗画面の `test/`、操作のフラグを追加した。
- 本番のコードのコメントに残っていたタスク番号 3 か所を削除した。

修正せずに残したこと：

- 商品の画像の登録は、`useApiMutation` を使わず、`onSuccess` で通知を直接書く。生成した API のクライアントを使わない multipart の送信で、通知に登録した枚数を入れ、途中で失敗しても再取得するため。
- 店舗画面の `<form action>` と `revalidatePath()` の URL は型で照合されない。Next.js の `typedRoutes` が型を付けないため、レビューで確認する。
