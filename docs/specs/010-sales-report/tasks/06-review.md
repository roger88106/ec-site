| 内容 | 理由 |

| 条件の商品の選択肢は、商品の一覧の API の 1 ページ（100 件）まで | 今の商品の数（seed で 15）では足りる。増えたら検索して選ぶ形に変える（管理画面の構成に書いた） |
| 写しの都道府県は、名前からコードへの読み替えの表で求める | 注文がお届け先をコードで持つようになるまでの間の形（レポートモジュールの設計書） |
