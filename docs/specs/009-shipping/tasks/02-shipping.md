## 出荷

- [x] **T9203** [テスト] 出荷の単体テスト（BR-19）：
  - 出荷済み → 配送中 → 配達完了、出荷済み → 配送中 → 返送

  - 途中を飛ばして進める（AC-177）
  - 配達完了と返送は入れ替わらない
  - 送り状番号の形（数字とハイフン、30 文字まで、ハイフンを除いて保存）
