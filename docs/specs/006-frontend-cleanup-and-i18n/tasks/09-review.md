### T6904 の結果：完了の確認

段階 9 の完了条件を満たした。DC と DN はすべて満たす（T6903 の表）。すべてのテスト、E2E、CI の検査が通る。

見直しで直したこと：

- 店舗画面の `<form action>` の文字列の URL を、見直しで確かめる所に足した（フロントの書き方 第 6 節）。
- API の列挙の値から組み立てる文言のキーを、キーの形の例外にした（同 第 7.2 節）。
- 画面の構成の文書に、文言の道具と置き場所、店舗画面の `test/`、操作の旗を書き足した。
- 本番のコードのコメントに残っていたタスク番号 3 か所を消した。

直さずに残したこと：

- 商品の画像の登録は、`useApiMutation` を使わず、`onSuccess` で知らせを直接書く。生成した API の口を使わない multipart の送信で、知らせに登録した枚数を入れ、途中で失敗しても取り直すため。
- 店舗画面の `<form action>` と `revalidatePath()` の URL は型で照らされない。Next.js の `typedRoutes` が型を付けないため、見直しで確かめる。
