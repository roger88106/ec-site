  - 手動の確認：未追跡の壊れたファイルがあっても、ステージした内容が正しければ commit できる。ステージした内容が壊れていれば停止する。どちらの後も作業ツリーが元に戻る。

  - 手動の確認（スクラッチの clone で実行）：未追跡の壊れたリンクの文書と、一部だけをステージした文書があり、ステージした内容が正しい場合は commit でき、未追跡のファイルとステージしていない行が残った。ステージした文書のリンクが壊れている場合は `doc-refs` で停止し、作業ツリーは変わらなかった。`git commit -a`（一時の index）でも、壊れた変更で停止した。既存の stash は変わらなかった。hook の時間は約 15 秒（取り出しと検査）。
