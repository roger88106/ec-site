# 通知モジュール

消費者へのメールを送る。今は出荷通知メールだけ。

| 項目 | 内容 |
|------|------|
| レベル | B（業務の規則は「同じ注文に同じ種類のメールは 1 通」だけで、集約に守らせる不変条件がない） |
| 依存 | 注文（イベントだけ。注文の API は呼ばない ※1） |
| 関連 spec | [009](../../specs/archive/mvp/009-shipping)、[011](../../specs/archive/mvp/011-dev-foundation)、[017](../../specs/archive/mvp/017-stability)、[155](../../specs/155-backend-structure) |

※1：メールに必要な値（宛先、注文番号、配送業者、送り状番号）は、イベント「注文の出荷」に載っている。

## 出荷通知メール

- イベント「注文の出荷」をコミットの後に受け、注文のメールアドレスへ送る。
- 件名と本文は日本語のテキスト。雛形はメッセージのファイル（`messages.properties` の `ecsite.notification.*`）に置き、注文番号、配送業者の表示名、送り状番号を差し込む。
- 送信元は設定 `ecsite.notification.from`。
- 消費者が配送業者のサイトで追跡できるよう、送り状番号は、ハイフンを除いた数字のまま載せる。

### 1 通だけ送る

| 項目 | 内容 |
|------|------|
| 記録 | 送ったメールを、注文 ID とメールの種類の組で記録する（一意制約） |
| 順序 | 同じトランザクションで、記録を挿入（すでにあれば何もしない）→ 挿入できたときだけ送る |
| 失敗 | 送信に失敗したら例外で終わり、記録も巻き戻る。未完了のイベントの再発行（[バックエンドのアーキテクチャ](../backend-architecture.md) 第 5 節）で再送する |
| 重複して届いた | 記録があるので送らない。同時に届いたら、後の挿入は先のコミットを待ってから何もしない |

- 送信が済んでからコミットに失敗したときだけ、2 通になりうる。DB のコミットの失敗はまれなので許容する。
- メールの送信は、外部サービスをトランザクションの外で呼ぶ決まり（[バックエンドの書き方](../../rules/backend-coding.md) 第 4.1 節）の例外にする。記録と送信を同じトランザクションにし、送信に失敗したら記録も取り消して再送するため（トランザクションの外で送ると、送った後に記録が失敗したとき 2 通になる）。SMTP にはタイムアウト（下の表）があり、リスナーは利用者の要求と別のスレッドで動くので、DB の接続を持つ時間は限られる。

## メールの送信

| 項目 | 内容 |
|------|------|
| port | 「メールを送る」の 1 つ（宛先、件名、本文）。SMTP の型とエラーを `infrastructure` の外に出さない |
| 実装 | Spring Boot のメール（`spring-boot-starter-mail`）で SMTP に送る。接続先は Spring Boot の設定 `spring.mail.*` |
| タイムアウト | 接続・読み・書きをそれぞれ 10 秒（`spring.mail.properties`）。タイムアウトがないと、応答しない SMTP サーバーでメールのリスナーが止まったままになる。タイムアウトで失敗したら、上の「失敗」と同じく再発行で再送する |
| ローカル・テスト・E2E | compose の Mailpit（SMTP は `localhost:2525`。ポートは `MAILPIT_SMTP_PORT` で変えられる。届いたメールは `http://localhost:8025` で確認する）。統合テストは Testcontainers の Mailpit |

## 構成

```
notification/
├── application/            # 注文の出荷のリスナー、出荷通知メールの作成
│   └── port/               # メールを送る、送ったメールの記録
└── infrastructure/
    ├── NotificationConfig  # 設定のクラス。設定の値の型を有効にする
    ├── mail/               # SMTP での送信と、その設定の値の型（NotificationProperties）
    └── persistence/        # 送ったメールの記録の実装
```
