# 段階 2：時間で待たない

- 前提：段階 1
- 完了条件：「起きないこと」を確かめるテストが、受け手の完了を待ってから数を確かめる。待つ時間の上限が、バックエンドと E2E でそれぞれ 1 か所にある。E2E の公開の開始のテストが準備の時間に頼らず、支払いの期限のテストの待ちが半分以下になる。時間で待つことの検査が、固定の時間を見る書き方を見つける。
