# 段階 5：入力のエラーの文

- 前提：段階 3
- 完了条件：注文手続きの画面は、入力の誤りの欄ごとの文を API の文のまま表示する。お届け先の郵便番号と電話番号の形の誤りは、業務のエラーと同じ文を返す。エラーの文に数字を直接書かない。US-57 のテストが通る。`./gradlew check`、`check-frontend.sh`、`check-all.sh` が通る。
