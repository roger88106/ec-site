### T6901 の結果：見直しで読む規則との照らし合わせ

本 spec で変えた所を、見直しで読む規則の一覧のフロントとコメントの行で照らした。

| 規則 | 結果 |
|------|------|
| 画面の URL（フロントの書き方 第 6 節） | 管理画面に URL の文字列を直接書いた所はない。店舗画面の `as Route` は IdP のログアウトの 1 か所で、理由のコメントがある。`revalidatePath()` と `<form action>`（検索・一覧の絞り込み）の文字列は型で照らされないので、確かめ方に `<form action>` を足した |
| 文言のキーの形（第 7.2 節） | API の列挙の値とエラーコードの表示名（`labels.publicationStatus.PUBLISHED` など）は、値からキーを組み立てるので値のまま。例外として書き足した |
| ロケールは 1 か所（第 7.3 節） | `Intl.*` にロケールを直接書いた所はない |
| console を直接呼ばない（第 8.2 節） | 本番のコードにない |
| catch では unstable_rethrow を先に（第 3.1 節） | サーバーアクションの catch は `withActionResult` の 1 か所で、守っている。ログインの直後のカートの移し替え（`api/cart.ts`）の catch はサーバーアクションでなく、try の中で移動しないので対象外 |
| コメント（コメントの書き方 第 6 節） | 段階 8 で直した。spec・plan・tasks の番号は本番のコードに残っていない |
