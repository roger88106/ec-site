# 段階 8：E2E と CI

- 前提：段階 4、6、7
- 完了条件：E2E がローカルと CI で通る。CI は外部の決済サービス・物流サービス・メールサーバーに接続しない。
- 参照：[plan](../plan.md) 第 10 節、[テストの実行方法](../../../guides/running-tests.md)

## タスク

- [x] **T9801** E2E の補助に、管理画面で出荷を登録する手順、mock の物流の画面で通知する手順、Mailpit で出荷通知メールを探す手順を追加する。メールは注文番号で探すので削除しない（ローカルのメールを残す）。mock の物流は画面を表示したバックエンドに通知するので、E2E の設定は必要ない。
- [x] **T9802** [E2E] 管理画面で出荷を登録 → mock の物流の画面で配送中・配達完了 → 店舗の注文詳細と一覧に配送状態が出る。Mailpit に出荷通知メールが届く。
- [x] **T9803** [E2E] 管理画面で出荷を登録 → mock の物流の画面で返送 → 管理画面で返送を絞り込み、在庫に戻してキャンセル → 支払状態が返金済みになり、在庫数が戻る。店舗の注文詳細がキャンセルになる。
- [x] **T9804** CI で E2E が通ることを確認する。
