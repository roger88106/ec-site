- 前提：段階 2
- 完了条件：cart に mapper があり、3 つのモジュールの presentation に、生成したモデルの引数を取るコンストラクターの呼び出しと、Controller の中の変換がない。media の公開の API が `api/` のクラスから service に委ねる。storefront に、加工のない写しの型と、並び順の重なった写しがない。既存のテストが、名前の変更のほかは変えずに通る。
- 参照：[plan](../plan.md) 第 3 節、第 5.4 節、第 6 節、[バックエンドの書き方](../../../../../rules/backend-coding.md) 第 1.1 節、第 2.2 節
