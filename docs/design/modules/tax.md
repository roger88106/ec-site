# 税モジュール

税区分と、適用期間付きの税率を管理する。指定時点の税率と税込価格を答える。

| 項目 | 内容 |

| 依存 | なし |

## 税区分（集約）

- 税区分は、名称と税率の一覧を持つ。税率は、率と適用期間を持つ。
- 適用期間は開始を含み、終了を含まない。空なら無期限。
- 率は 0 以上 100 未満、小数第 2 位まで。

### 税率は一覧ごと置き換える

税率を 1 件ずつ変える操作は作らず、一覧ごと置き換える操作だけを作る ※1。置き換えでは、現在時刻と比較して次を検証する。

1. 期間が重複せず、途切れず、最後の税率の終了は空。
2. 既存の税率は、状態ごとに変えられる範囲が決まっている。

   | 既存の税率 | 変更・削除 |
   |------------|------------|
   | 開始済み（開始が空を含む） | 率と開始は変えられず、削除もできない。終了は現在より後に変えられる |
   | 終了済み | できない |
   | 未開始 | できる |

3. 新しく設定する開始・終了は、空か現在より後。

※1：期間限定の税率を追加するには、既存の税率の終了の変更と新しい税率の追加を同時に行う必要があり、1 件ずつでは途中で期間が途切れるため。

指定時点の税率は、その時点を含む税率（期間は重ならないので 0 件か 1 件）。

### 不変条件の置き場所

| 不変条件 | ドメイン | DB |
|----------|----------|----|
| 期間が重複しない | 置き換え時の検証 | 排他制約 |
| 途切れがない、最後は無期限 | 置き換え時の検証 | なし（テストで担保） |
| 開始済み・終了済みの変更制限 | 置き換え時の検証 | なし |
| 率の範囲 | 率の値オブジェクト | CHECK 制約 |

## 税込価格

税抜価格 ×（100 ＋ 率）÷ 100 の 1 円未満を切り捨てる。誤差の出ない十進数で計算する。商品カタログも、並べ替え・絞り込みのため SQL で同じ計算をする（[catalog.md](catalog.md)）。

## 税率ごとの消費税額

注文の金額は、適格請求書の端数処理に合わせ、税率ごとに 1 回だけ消費税額を計算する。

- 入力は、税率と税込金額の組の一覧（品目の小計と送料）。
- 税率ごとに税込金額を合計し、合計 × 率 ÷（100 ＋ 率）の 1 円未満を切り捨てる。品目ごとには端数処理しない。

## 構成

```
tax/
├── api/                    # 税率の予定の一覧、税込価格・消費税額の計算
├── presentation/           # admin.yaml から生成したインターフェースを実装
├── application/            # 税区分の作成、税率の置き換え、参照
│   ├── model/              # コマンド（command）と表示の型（view）
│   └── port/               # 税区分の参照用リポジトリ
├── domain/                 # 直下に、エラーの定義（TaxErrorCode）
│   └── taxcategory/        # 税区分（集約）、税率、税の計算。vo/ は率と適用期間、port/ はリポジトリ
└── infrastructure/
    ├── TaxDomainConfig     # 設定のクラス。domain の Factory を Spring の部品にする
    └── persistence/        # リポジトリと参照用リポジトリの実装
```
