## 方針

- 候補は、skill `review` の文書のレビューの手順で挙げる（日本語だけの文脈のサブエージェントに見本を渡す）。
- 候補は表（ファイル、行、今の書き方、修正案、理由）で示す。利用者が採否を決め、採ったものだけを修正する。
- 意味、番号、節の番号と構成、表の構成は変えない（DC-193）。
- tasks には、範囲ごとに、修正したファイルと内容の要約だけを書く。手順は書かない。
- 1 回の提示は、目安として 1,000 行以内にする。
