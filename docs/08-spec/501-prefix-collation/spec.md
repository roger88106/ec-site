# Spec 501：前方一致で検索する列の照合順序を C にし、索引を使えるようにする

種類：整理　規模：M　ステータス：確定

## 背景と目的

管理画面の注文一覧と商品一覧には、注文番号、商品品番、バリアント品番を前方一致で絞り込む検索がある。ローカル、CI、統合テストの DB は照合順序が C でないので、この 3 つの検索は一意制約の索引を使えず、テーブルを全件走査している（[#501 の調査のコメント](https://github.com/roger88106/ec-site/issues/501#issuecomment-6969967992)）。3 列の照合順序を C にし、商品一覧の絞り込みの形を変えて、どの環境でも索引を使えるようにする。消費者・運営者に見える振る舞いは変えない。追跡の issue は #501、全体の issue は #544（段階 3）。

## スコープ

| 含める | 含めない |
|--------|----------|
| 注文番号、商品品番、バリアント品番の照合順序を C にするマイグレーション | 店舗のキーワード検索（部分一致） |
| 管理画面の商品一覧で品番を絞り込む検索の書き換え | DB 全体の照合順序 |
| 索引を使うことを確認する統合テスト | 在庫調整が持つ注文番号の列 |
| 前方一致で検索する列の規則の追加 | 本番の DB の照合順序の確認 |

決定（2026-11-18）：

- 対象は 3 列全て。管理画面の商品一覧の品番の絞り込みは、後で導入する検索エンジンに置き換えない対象として扱う。店舗のキーワード検索は、検索エンジンに置き換える予定なので対象外。
- 列の照合順序を C にする。前方一致のための索引を追加する案と、DB の作成時に DB 全体を C にする案は採らない。既存の一意制約の索引をそのまま使う。
- 規模は M（特例）。DB の構造を変えるので判定の表では L だが、2 つのモジュールに同じ機械的な変更をするだけで、plan に書く設計の決定がないため。issue 担当のセッションが承認した。
- マイグレーションは、モジュールごとに 1 つずつ書く（注文と商品）。理由：マイグレーションの名前は、先頭にモジュール名を付ける形のため。
- 並び順は変わらない。理由：品番は英大文字・数字・ハイフンだけ、注文番号は数字とハイフンだけで、ローカル・CI・統合テストの DB の照合順序でも、この文字の並び順は C と同じため ※1。
- 3 列を他のテーブルの列と比べる処理は、アプリにもマイグレーションにもない。照合順序の違う列どうしの比較は起きない。
- 商品一覧の品番の絞り込みの形を変える。理由：今の形は、商品品番の条件とバリアント品番の条件を 1 つの条件にまとめており、照合順序を C にしても、商品のテーブルを全件走査するため。条件ごとに索引で探し、結果を合わせる形にすると、両方の索引を使う（#501 のコメント）。店舗の検索を変えないという利用者の決定は、検索エンジンに置き換える店舗の検索についてのもので、この書き換えは含まない。
- 「前方一致で検索する文字列の列は、照合順序を C にする」を、`backend-coding.md` の「マイグレーション」に規則として追加する。理由：後で前方一致の検索を追加するときに、同じ問題を繰り返さないため。確認方法はレビュー。
- 照合順序の変更は、`backend-coding.md` の「前のリリースのアプリが動き続けられる変更だけにする」で 3 段に分ける変更（列の型の変更）に当たらず、1 つのリリースで変える。理由：型と長さは変わらず、前のアプリの SQL（等号、前方一致、挿入）はそのまま動くため。変更の間はテーブルがロックされ、一意制約の索引を再作成するが、本番の環境はまだないので、今は影響がない。

※1：文字の種類は、品番の形式の検証（`CodeFormat`）と注文番号の形式の検証（`OrderNumber`）による。並び順は、ローカルの DB で、ハイフンを含む値を両方の照合順序で並び替えて確認した。

## 目的と完了条件

### DS-501-1 前方一致の検索が、どの環境でも一意制約の索引を使う（D / P1）

- **DC-501-1** 注文番号の前方一致の検索（アプリが作る SQL）が、注文番号の一意制約の索引を使う。
- **DC-501-2** 管理画面の商品一覧の品番の絞り込み（アプリが作る SQL）が、商品品番の一意制約の索引と、バリアント品番の一意制約の索引を使う。
- **DC-501-3** 3 列の照合順序が C であることが、マイグレーションに書かれている。

### DS-501-2 検索の結果を変えない（D / P1）

- **DC-501-4** 3 つの絞り込みの結果（該当する行、件数、ページング、並び順）が変わらない。
