# 決定記録

決定の理由を、1 つの決定につき 1 ファイルで書いておく。

## 形

- ファイル名は英語の短い名前（例：`subagent-delegation.md`）。
- 節は、背景・決定・理由・日付・関連の 5 つ。
- 決定を変えたときは、新しいファイルを書き、古いファイルの「関連」に新しいファイルを書く。古い決定は書き換えない。
- この形は、spec 4（設計書の型と試作）で改めてよい。
