# Spec 900：注文の機能仕様を、固定の節の形に書き換える

種類：整理　規模：M　ステータス：確定

見本。実在の spec ではない。番号 900 は見本用で、題材は注文の機能仕様の書き換えである。

## 背景と目的

[注文モジュール](../../../../03-機能仕様/order.md)を、固定の節の形に書き換える。消費者・運営者に見える振る舞いと、コードは変えない。

## スコープ

| 含める | 含めない |
|--------|----------|
| 注文の機能仕様の節の並びと、各節に書くことの修正 | 他のモジュールの機能仕様 |

決定：

- 節の名前と順は、書き換えた機能仕様の全てで同じにする。
- 業務規則の本文に、spec・plan・tasks の番号を書かない（[文書の書き方](../../../../05-開発規則/writing.md)の「表と注」）。

## 目的と完了条件

### DS-900-1 注文の機能仕様を、固定の節の形で読めるようにする（D / P1）

- **DC-900-1** 注文の機能仕様の節が、決めた名前と順に並んでいる。
- **DC-900-2** 業務規則の本文に、AC や BR の番号がない。
- **DC-900-3** 書き換え前の業務規則が、欠けずに書き換え後の節にある。

### DS-900-2 文書の検査が通る（D / P1）

- **DC-900-4** `node scripts/ci/doc-refs.mjs` が通る。
- **DC-900-5** 書き換えた節の `ja-text` の warning が 0 である。

## 変える範囲

| まとまり | ファイル |
|----------|----------|
| 機能仕様 | `docs/03-機能仕様/order.md` |

## 非機能要件

- **DN-900-1** 消費者・運営者に見える振る舞いを変えない。コードも変えない。
- **DN-900-2** アーカイブした spec を変えない。
