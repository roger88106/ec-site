## 段階 5 の確認（T9504）で追加したタスク

- [x] **T9406** [テスト] SMTP サーバーが接続を受けても応答しないとき、送信がタイムアウトで失敗し、メールの記録が残らないこと（再発行で再送できること）の統合テスト。
- [x] **T9407** SMTP の接続・読み書きのタイムアウトを設定する（`spring.mail.properties`）。タイムアウトがないと、応答しない SMTP サーバーでリスナーが止まったままになる。T9406 を通す。
- [x] **T9408** compose の Mailpit の SMTP のポートを、環境変数 `MAILPIT_SMTP_PORT`（既定 1025）で変えられるようにし、ローカルの設定も同じ値を読む。開発環境の起動に書く（1025 を Windows の他のプログラムが使っていると、ローカルのバックエンドのメールが Mailpit に届かない）。
