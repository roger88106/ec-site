  - 登録は、呼んだ側のトランザクションの中でアセットを記録する。トランザクションがなければ失敗する。
  - 破棄は、用意で置いたファイルを削除する。削除するのに失敗しても例外を投げず、warn のログに保存先のキーを出力する（AC-305）。
