## 実装

- [x] **T7102** ShedLock を依存に追加し、ロックのテーブルを Flyway のマイグレーションで `common` schema に作る。スケジューラーを有効にする設定を `config` に置く。テストでは定期ジョブを自動で動かさず、テストから呼ぶ。
- [x] **T7103** [テスト] 分散ロックの統合テスト：同じジョブを 2 つのスレッドから同時に起動しても、1 回だけ動く。
- [x] **T7104** [テスト] 未完了イベントの再発行の統合テスト：
  - 1 回目に失敗したリスナーが、再発行で処理される
  - 5 分より新しい未完了のイベントは再発行しない
