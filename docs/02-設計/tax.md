# 税の設計

税モジュールは、税区分と適用期間付きの税率を管理し、税込価格と税率ごとの消費税額を計算する。業務規則は [税モジュール](../03-機能仕様/tax.md) にある。

| 項目 | 内容 |
|------|------|
| レベル | A（期間の重複・途切れの禁止、開始済みの税率の変更制限など、不変条件が多い） |

## 境界

依存は[全体構成](overview.md)の「モジュールの依存とイベント」。

### 他のモジュールへの公開

| 種類 | 内容 | 利用者 |
|------|------|--------|
| API | 税区分ごとの税率の一覧（予定を含む）、指定時点の税率、税込価格の計算 | 商品カタログ、注文 |
| API | 税率ごとの消費税額の計算 | 注文 |

## 処理の流れ

なし。モジュールをまたぐ処理は、他のモジュールが税の API を同期で呼ぶだけで、税から他のモジュールへの呼び出しはない。

## API

操作の一覧は[ロールと権限の対応表](role-permissions.md)、リクエストとレスポンスの項目は OpenAPI（[店舗 API](../../api/openapi/store.yaml)、[管理 API](../../api/openapi/admin.yaml)）。

店舗 API に税の operation はない。

## パッケージの構成

```
tax/
├── api/                # 税率の予定の一覧、税込価格・消費税額の計算
├── presentation/       # 管理 API の実装
├── application/        # 税区分の作成、税率の置き換え、参照
│   ├── model/          # コマンドと表示の型
│   └── port/           # 参照用リポジトリ
├── domain/             # エラーの定義
│   └── taxcategory/    # 税区分（集約）、税率、税の計算
│       ├── vo/         # 率、適用期間
│       └── port/       # リポジトリ
└── infrastructure/     # 設定、永続化
    └── persistence/    # リポジトリと参照用リポジトリの実装
```
