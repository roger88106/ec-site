# 開発規則

開発の進め方、文書とコードの書き方、レビューなどの規則を置く。文書を追加したら、下の表に行を加える。

| 文書 | 内容 |
|------|------|
| [workflow.md](workflow.md) | 開発の進め方（SDD・TDD）、起票と規模、利用者の確認、完了の定義、コードと文書の食い違い |
| [issues.md](issues.md) | 起票と記録の操作（起票、AC 一覧の操作、アーカイブの操作、構成が決まっていないときの試作） |
| [merging.md](merging.md) | マージと後片付け（マージの許可と後片付け、pull request のレビューの対応） |
| [glossary.md](glossary.md) | 開発の用語集（開発の進め方・ツール・テスト・セッションの役割などの用語） |
| [notation.md](notation.md) | spec・tasks とモジュールの設計書の記号と番号 |
| [review.md](review.md) | 書き方の規則の書き方とレビュー |
| [comments.md](comments.md) | コメントの書き方 |
| [writing.md](writing.md) | 文書の書き方（言語、論理名と物理名、表と注、用語の選び方、言い回しと論理） |
| [doc-structure.md](doc-structure.md) | 文書の構成（文書の置き場所、参照、spec と plan の書き方、文書の長さの基準、文書の種類ごとの雛形） |
| [subagents.md](subagents.md) | エージェントの作業フロー（サブエージェントへの任せ方） |
| [resources.md](resources.md) | 作業の形と使用量（profile の決め方、止める閾値、使用量を読む頻度） |
| [backend-coding.md](backend-coding.md) | バックエンドの書き方 |
| [frontend-coding.md](frontend-coding.md) | フロントの書き方 |
| [test-writing.md](test-writing.md) | テストの書き方 |
| [api-conventions.md](api-conventions.md) | API の規約 |
| [licenses.md](licenses.md) | 依存とライセンス |
