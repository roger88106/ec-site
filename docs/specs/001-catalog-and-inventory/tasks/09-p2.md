# 段階 9：P2

MVP のコアフロー（P1）がすべて終わってから、余力に応じて行う。各項目は着手時にタスクへ分解する。

| 項目 | AC | 着手前に必要なこと |
|------|----|--------------------|
| 公開日時の予約（US-6） | AC-34〜36 | なし（API とテーブルは用意済み） |
| バリアントの販売停止（AC-28） | AC-28 | なし（API とテーブルは用意済み） |
| 商品画像（US-7） | AC-37〜40 | plan に画像の設計（署名付き URL、ストレージ、API）を追記する。ローカル用の S3 互換エミュレーターを選ぶ（constitution 16） |
| 画像形式の受け付けと WebP 変換（US-13） | AC-67〜70 | US-7 の後。対応形式と、変換の方式（同期・非同期）を plan に追記する |
