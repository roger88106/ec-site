# 段階 6：支払の期限切れのジョブ

- 前提：段階 3（決済サービスのエラーの分類）
- 完了条件：US-67 のテストが通る。1 件の例外で他の支払の処理が止まらず、与信の通知を待つ支払がたまっても新しい期限切れの支払を処理する。長く待つ支払の件数が警告のログに出る。既存のテストがすべて通る（`./gradlew check`）。
