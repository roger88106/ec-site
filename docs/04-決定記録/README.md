# 決定記録

決定の理由を、1 つの決定につき 1 ファイルで書いておく。

## 形

書き方と骨組みは、雛形 [template.md](template.md)。

- ファイル名は英語の短い名前（例：`subagent-delegation.md`）。
- 節は、背景・選択肢・結論・日付・関連の 5 つ。
- 決定を変えたときは、新しいファイルを書き、古いファイルの「関連」に新しいファイルを書く。古い決定は書き換えない。

## 文書

| 文書 | 内容 |
|------|------|
| [template.md](template.md) | 決定記録の雛形 |
| [order-capture-before-shipment.md](order-capture-before-shipment.md) | 出荷の登録で、注文を出荷済みにする前に売上を確定する |
| [subagent-delegation.md](subagent-delegation.md) | サブエージェントへの任せ方で取り入れたもの |
