# 段階 7：管理画面（`frontend/admin`）

- 前提：段階 1〜5（B 側 API）
- 完了条件：B 側の操作が画面からひととおりでき、下記の手動確認が全て通る。CI でフロントのジョブが通る。
- 参照：constitution 2（フロントエンド）、[plan](../plan.md) 第 3 節、[管理画面の構成](../../../design/apps/admin.md)、`admin.yaml`
- 画面は、管理画面の構成の第 9 節（画面を追加する手順）に沿って作る。

## 骨格

- [x] **T701** Vite + React + TypeScript のプロジェクトを作る（pnpm、Tailwind CSS、shadcn/ui、TanStack Query、React Router、React Hook Form、Biome）。管理画面の構成の第 2 節のディレクトリと、Sidebar のレイアウト、toast を用意する。
- [x] **T702** `admin.yaml` から `openapi-typescript` で型を生成するスクリプトを作り、ビルド前に実行する（生成物はコミットしない）。API の呼び出しは `openapi-fetch` + `openapi-react-query`。エラーの応答を `ApiError` に変換し、4xx は繰り返さない。開発時は Vite のプロキシでバックエンドに転送する。
- [x] **T703** エラーの表示：エラーレスポンスの `message` をそのまま表示し、入力検証エラーは項目ごとに表示する。バージョン不一致（409）では「他の人が先に更新しました。再読み込みしてください」と再読み込みのボタンを表示する。取り消せない操作の確認のダイアログを用意する。

## 共通の部品

- [x] **T704** [テスト] 価格表示（「1,980 円（税抜 1,800 円）」。BR-4）と、日本時間での日時の表示・入力（BR-3）の単体テスト（Vitest）。
- [x] **T705** 価格表示と日時の部品を実装する。T704 を通す。

## 画面

- [x] **T706** 税区分：一覧（現時点の率）、登録、税率の一覧の編集（開始・終了の空白を扱える。期間の重複・途切れはサーバーのエラーを表示する）。
- [x] **T707** カテゴリ：木の表示、登録、名称の変更、並び替え、削除。
- [x] **T708** 商品一覧：絞り込み（品番、商品名、状態、カテゴリ）、ページング。在庫数の合計は在庫の集計 API を呼んで組み合わせる（AC-49）。
- [x] **T709** 商品の登録・編集：基本情報（税抜価格を含む）、軸、バリアント（登録・削除・並び替え）、公開・非公開・販売終了、削除。品番の入力は英小文字を大文字に変換してから送る。
- [x] **T710** 在庫：バリアントごとの在庫数、調整（増減量・理由・メモ）、履歴。

## 仕上げ

- [x] **T711** CI にフロントのジョブを追加する（lint、型チェック、テスト、ビルド）。
- [x] **T712** 手動確認：seed のデータで、税区分の期間限定の税率の設定（AC-4 のシナリオ）、商品の登録から公開まで、在庫の調整までを画面で行う。
  - 段階 9 で自動にした：AC-4 のシナリオの一覧の作成と保存、入力中の 409 と再読み込みは結合テスト（T902）、商品の登録から公開・在庫の調整までは E2E（T907）。目視で確認するのは見た目（配置、狭い画面）だけになる。
