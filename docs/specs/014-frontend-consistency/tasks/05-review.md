## レビューの結果

### 修正したこと

- 金額・価格・日時・税額・郵便番号・軸の値の整形を、共有パッケージの 1 か所（`lib/format.ts`）にし、2 つの画面の同じ関数を削除した。共有パッケージに、共有の文言だけを引く文言の関数を置いた。
- 管理画面の日本時間の差（9 時間、`+09:00`）と `sv-SE` の直書きをなくし、共有のロケールとタイムゾーンから求める形にした。
- 共有の文言を、2 つの画面で同じ役割の文だけにした（管理画面だけが使う文は管理画面の `app.common.*` へ、同じ役割の注文・金額の項目は `common.*` へ）。文言の 2 か所の句点の後の空白を削除した（DC-159）。
- 店舗画面の注文の表示のファイルを、表示名・注文の状態の判定・引当の残り時間・数量の選択肢に分けた。2 つの画面の表示名を、使う機能の数で `lib/labels.ts` か機能の `labels.ts` に置いた。
- 1 か所にまとめたもの：URL のクエリの読み取り、UUID と日付の形の判定、会員の操作のサーバーアクションの 401 と成功の後の移動、商品の画像の表示、ラベル付きのチェックボックス、カテゴリの選択肢。
- モジュールの読み込み時に文言を引く所（店舗画面 4 か所、管理画面 6 か所）を、使う時に引く形にした。
- 店名を共有の文言に置き、店舗画面のヘッダーと題名、管理画面の HTML の題名とサイドバーを文言から作った。
- 契約に定数のある値（カテゴリの深さ、商品の一覧の件数の上限）を、生成した定数から読む形にした。TypeScript を 4 つのパッケージで `~6.0.3` にそろえ、`strict` を共通の設定に置いた。使っていない依存を 3 つ削除した。
- 検査を追加した：テストの差分の検査が、テストのファイルをまたぐ移動を認める。文言のキーのコメントの検査（`message-comments.mjs`）。手元の `check-frontend.sh` が共有パッケージも実行する（T014-05-08）。

### 修正せずに残したこと

| 項目 | 理由 |
|------|------|
| 管理画面の価格の整形のテストの 4 行で、呼び出しの形を変えた | 共有パッケージの価格の整形はオブジェクトを受ける（plan 第 3.1 節）。期待する文は変えず、利用者と決めて DN-18 の例外にした（T014-04-01） |
| 2 つの画面の `lib/utils.ts` が同じ中身 | shadcn/ui の生成物が読む置き場所で、中身は共有パッケージの `cn` を再エクスポートする 1 行 |
| 管理画面の `report.test.ts` の describe の名前「レポートの表示名」の中に、グラフの金額の短い表示のテストだけが残る | 表示名のテストを `labels.test.ts` に移した残り。DN-18 で describe の名前を変えない |
| ラベルと区切り線を共有パッケージに残した | 管理画面の `components/ui/` も使う（T014-02-09） |
