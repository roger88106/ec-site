# 段階 8：店舗画面（`frontend/store`）

- 前提：段階 6（C 側 API）
- 完了条件：C 側の閲覧が画面からひととおりでき、下記の手動確認が全て通る。CI でフロントのジョブが通る。
- 参照：constitution 2（フロントエンド）、[plan](../plan.md) 第 3 節、[店舗画面の構成](../../../design/apps/store.md)、`store.yaml`
- 画面は、店舗画面の構成の第 8 節（画面を追加する手順）に沿って作る。

## 骨格

- [x] **T801** Next.js（App Router）+ TypeScript のプロジェクトを作る（pnpm、Tailwind CSS、shadcn/ui、Biome、Vitest）。
- [x] **T802** `store.yaml` から型を生成するスクリプトを作り、ビルド前に実行する。API はサーバーコンポーネントから `openapi-fetch` で呼ぶ。API の結果のキャッシュは最大 60 秒にする（NFR-1）。

## 共通の部品

- [x] **T803** [テスト] 価格表示（BR-4）と、バリアントの選択（選べない値の判定、選んだバリアントの特定。AC-62、63、28）の単体テスト（Vitest）。
- [x] **T804** 価格表示の部品と、バリアントの選択の関数を実装する。T803 を通す。

## 画面

- [x] **T805** トップ：カテゴリの一覧と、新着の商品。
- [x] **T806** 商品一覧：カテゴリ、価格帯での絞り込み、並び替え、ページング。在庫なしの表示（AC-51〜57）。
- [x] **T807** 検索結果（AC-58〜61）。
- [x] **T808** 商品詳細：軸ごとの選択。在庫切れ・販売停止の選択肢は選べない状態（グレー）で表示する。商品の価格と、選んだバリアントの在庫の有無を表示する（AC-62〜64、28）。表示されない商品は「見つかりません」の画面（AC-65）。

## 仕上げ

- [x] **T809** CI にフロントのジョブを追加する（lint、型チェック、テスト、ビルド）。
- [x] **T810** 手動確認：管理画面で商品を公開・非公開・販売終了にし、店舗画面での見え方を確認する。税区分の違う商品で、価格順の並びが税込で正しいことを確認する。
  - 段階 9 で自動にした：公開したときの見え方は E2E（T907）、非公開・販売終了の見え方と税込の価格の並びは E2E（T908）。目視で確認するのは見た目だけになる。
- [x] **T811** spec 001 の完了確認：P1 の全 AC にテストがある（バックエンド）か、手動確認の項目がある（画面）。plan と各モジュール設計書が実装と一致している。
