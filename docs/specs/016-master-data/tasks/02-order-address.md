# 段階 2：注文のお届け先のコードと移行

- 前提：段階 1
- 完了条件：注文はお届け先の都道府県と市区町村を、コードと注文の時点の名前で持つ。注文の確定はコードを地域モジュールで確かめる。既存の注文が移行で新しい形になり、照らせない注文があれば移行が失敗する。AC-251、258、261 のテストと、店舗 API・管理 API の注文の応答のテストが通る。`./gradlew check` が通り、ローカルの DB が移行の後に起動する。画面の型の検査は段階 3 まで通らない（plan 第 14 節 ※13）。
- 参照：[plan](../plan.md) 第 2.1〜2.3 節、spec の US-54、56、BR-34、35、NFR-22、[注文モジュール](../../../backend/modules/order.md)、[バックエンドの書き方](../../../backend/coding.md) 第 1.3、3.1 節
